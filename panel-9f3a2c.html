El Closet de Juli Panel de administracion

Todo ocurre dentro de este navegador: no hay servidor y ningun dato sale de este dispositivo. Este panel no publica — para que los cambios se vean en el sitio hay que generar datos.js y reemplazar con el js/datos.js del repositorio, ya sea subiendo el archivo desde la computadora o pegando el texto en GitHub desde el telefono.

No se encontro js/datos.js. El panel arranca con un catalogo vacio: se puede trabajar igual y generar el archivo al final.
Conexion con GitHub

Con esto configurado, el boton Publicar sube los cambios y las fotos directamente, sin mover archivos a mano. Se configura una vez por dispositivo.

GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens. Dar acceso solo a este repositorio, con el permiso Contents: Read and write y nada mas. Poner vencimiento de 90 dias.

El token se guarda en el almacenamiento de este navegador y solo viaja a api.github.com. No queda en el codigo ni se sube al repositorio. Aun asi, quien use este dispositivo desbloqueado puede publicar: configuralo solo en equipos propios, usa un token fine-grained limitado a este repositorio y borralo con Olvidar token si prestas o perdes el equipo.

Archivo datos.js

Este texto reemplaza por completo el archivo js/datos.js del repositorio.
Desde la computadora: Descargar, y mover el archivo a js\datos.js.
Desde el telefono: Copiar, abrir js/datos.js en GitHub, tocar el lapiz, seleccionar todo, pegar y confirmar.
